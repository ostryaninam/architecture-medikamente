
# Отчёт по устранению узких мест при миграции системы


# Отчёт: Выявление узких мест при миграции монолита в микросервисную архитектуру

**Дата:** 19.08.2025

###  1. Выявленные проблемы

Потенциальные узкие места при миграции:

### Персонал
- Нехватка компетенций (новые технологии, микросервисы, DevOps)
- Отсутствие выделенной команды под микросервисную разработку
- Сопротивление изменениям, устаревшая оргструктура

### Инфраструктура
- Недостаток серверных мощностей
- Отсутствие масштабируемости БД
- Нет среды для деплоя, CI/CD, мониторинга и логирования
- Отсутствие поддержки API

### Процессы
- Отсутствие документации и автоматизации
- Передача данных вручную
- Долгий процесс деплоя
- Нет тестирования
- Отсутствие DevOps-культуры

### Интеграции
- Нестабильные каналы
- Нет контрактов взаимодействия между сервисами
- Сильная связанность компонентов

### Архитектура
- Сложная модификация легаси-кода
- Отсутствие модульности
- Нет внедрённой БД и авторизации

### 2. Рекомендации по устранению узких мест

### Персонал

| Мера | Приоритет |
|------|-----------|
| Обучение текущей команды (включая вики, инструкции, мотивацию) |  Высокий |
| Найм новых сотрудников (разработка, DevOps) |  Высокий |
| Пересмотр оргструктуры под команды микросервисов |  Средний |

### Инфраструктура

| Мера | Приоритет |
|------|-----------|
| Добавление серверных мощностей или выбор облака |  Высокий |
| Развёртывание кластерной СУБД для масштабируемости | Высокий |
| Построить Dev/Test/Prod окружения, внедрить CI/CD пайплайны | Высокий |
| Развернуть мониторинг и логирование (например, Prometheus + Grafana, ELK) | Средний |

### Процессы

| Мера | Приоритет |
|------|-----------|
| Внедрение документации |  Высокий |
| Внедрение тестирования, найм QA |  Высокий |
| Ввести devops-культуру |  Средний |
| Создать вики-пространство с инструкциями и материалами — для общего понимания новых процессов. |  Средний |

### Интеграция

| Мера | Приоритет |
|------|-----------|
| Контрактное проектирование API |  Высокий |
| Переход на защищённые каналы (HTTPS, mTLS, VPN) |  Высокий |

### Архитектура

| Мера | Приоритет |
|------|-----------|
| Использование архитектурных паттернов и High-Level Design | Высокий |
| Постепенный переход через Branch by Abstraction | Высокий |

### 3. Заключение

Для успешной миграции необходимо работать системно: не только технически модернизировать систему, но и трансформировать процессы, культуру и организационную структуру. Предложенные шаги направлены на снижение рисков и создание устойчивой новой архитектуры.
